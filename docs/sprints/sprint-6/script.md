# Interview script

### 1. Review Action Points from Last Meeting
* "Last week, we committed to deploying the 'Assignment Task Files' and 'Student Submission' features by Monday, Dec 8th."
* "We successfully deployed those, and today we want to formally demonstrate the full workflow and check if there are any issues."

### 2. Demo: File Management & Submissions
* **Instructor Workflow (Task Description):**
    * "First, I'm logging in as an Instructor."
    * "I'll go to an existing assignment component and upload a 'Task Description' file (e.g., a PDF spec)."
    * "This file is now immediately available for all students in the group."
* **Student Workflow (Submission):**
    * "Now, switching to the Student view."
    * "I can see the task description you just uploaded."
    * "I will upload my solution file here. The system confirms the submission is received."
* **Grading Workflow (Downloading):**
    * "Back to the Instructor view in the grading table."
    * "You can see an icon indicating this student has submitted."
    * "I can click right here in the table to download and view their file, then enter the grade immediately next to it."

### 3. Discuss Product Backlog & Deadlines

* "The final major feature remaining on our roadmap is the **Peer Review** system."
* "Our plan is to focus entirely on this for the upcoming week."

### 4. Agree on Further Steps
